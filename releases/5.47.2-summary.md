# Warlock.js 5.47.2 — release summary

Released 2026-11-07.

All **33 packages** (`@warlock.js/*` and `create-warlock`) move to 5.47.2 together;
keep every family package on the same version. This patch makes release notes show
what newer versions changed, lets app CLI commands use the queue, gives each project
its own dev dependency cache, and warns early about imports the production build
rejects. The packages with changes are `core` and `web`.

---

## 1. Release notes check online (`core`)

- `npx warlock release-notes` prints the installed version's notes, then a "Newer
  releases (not installed)" section with what later versions changed, breaking changes
  first, and the update command. `--from <version>` runs to the latest release;
  `--to` caps it.
- `--json` reports `installedVersion`, `latestVersion` and, per release, `installed`
  and `source`. Run it before upgrading and before reporting a framework bug.
- `--offline` keeps the bundled-only behaviour. When the check fails, the bundled
  notes print with one line saying why.

---

## 2. CLI commands (`core`)

- A command with `preload: { configuredConnectors: true }` starts the early-phase
  connectors listed in `warlock.config.ts > connectors` (such as the queue) without
  importing every module's `main.ts`.

---

## 3. Dev server and checks (`web`, `core`)

- `warlock dev` keeps optimized dependencies in a folder per project root, so several
  checkouts sharing one `node_modules` no longer break each other with "Outdated
  Optimize Dep". `webConnector({ cacheDir })` sets the folder.
- `warlock dev` and `warlock check` (`WL9027`) warn when code the server bundle
  compiles imports a static asset or a `?raw`, `?url` or `?worker` query, which the
  production build rejects or may fail on. The build itself is unchanged.

---

## 4. Upgrade notes

1. **Update the family.** Run `npx warlock update`.
2. **Read what changed.** Run `npx warlock release-notes --from 5.47.1`.
3. **Old dev caches.** `node_modules/.vite/warlock-dev` is no longer used and can be
   deleted.
