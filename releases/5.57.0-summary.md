# Warlock.js 5.57.0 — release summary

Released 2026-11-18.

All **34 packages** (`@warlock.js/*` and `create-warlock`) move to 5.57.0 together;
keep every family package on the same version. This minor rebuilds the look of the
devtools dashboard and of its Grimoire tab, adds a Features view to the Grimoire tab,
and makes the Grimoire tab fast to open on large apps. The packages with changes are
`devtools` and `grimoire`; `core` ships this summary for `warlock release-notes`.
Nothing changes in how an app runs.

## Check first

- **Package panel stylesheets.** A panel stylesheet should use only the CSS variables in
  `DEVTOOLS_PANEL_TOKENS` (plus variables it defines itself). A variable outside the list
  is not defined by the dashboard and renders with the browser's default colour.

---

## 1. What changed most

- **A new dashboard look.** A left sidebar lists the tabs with icons, grouped as
  Monitor, Application, AI and Packages. A slim top bar holds the instance picker, a
  theme toggle (system, light, dark, saved in the browser) and the account menu. On a
  phone the sidebar becomes a slide-over menu. Ctrl/Cmd+K opens a command palette that
  jumps to any tab, the account page or an admin page.
- **Readable in both themes.** The light and the dark theme use a tinted palette with one
  brand colour, and every text colour meets WCAG AA contrast (4.5:1) on the page and on
  cards. A spec checks the contrast and that every listed token is defined in both themes.
- **Listings you can scan.** Every built-in tab opens with a description and its actions,
  a row of summary figures and a filter bar with result counts. Status codes, methods and
  log levels are colour-coded, durations show a bar against the rest of the list, table
  headers stay in view, and rows open with the keyboard.
- **The Grimoire tab, rebuilt.** A tab bar (Overview, Features, Apps, Tasks, Releases,
  Check, Modules) with counts and breadcrumbs, and a search box you reach with `/`. The
  new Features view lists every feature with its status, version, summary and flows, with
  filters, sorting and counts. Apps groups pages and screens by route segment with a
  filter and shows whether each one is confirmed or inferred. Check keeps what to fix
  apart from expected findings.
- **A fast Grimoire tab.** In production the tab keeps the opened book until the book
  changes and starts opening it when the app starts, so the first visit does not wait.
  In development it waits for a reopen only when files were added or removed, and
  otherwise serves the open book while it refreshes in the background. While a large book
  opens, the tab shows "Opening the book…" instead of a blank area.

## 2. New options and APIs

- **Panel options.** The devtools `panels` option accepts `[specifier, options]`
  entries. The options object reaches the panel factory next to `root` and `mode`:

  ```ts
  panels: [["@warlock.js/grimoire/devtools", { ttlMs: 60_000 }]],
  ```

  An invalid entry is reported with what to change and skipped; the other panels still
  load.

- **`DEVTOOLS_PANEL_TOKENS`** (from `@warlock.js/devtools`): the CSS variables a package
  panel stylesheet may use. See "Styling a panel" in the devtools docs.
- **Grimoire data routes.** New `/features` route; `/apps` rows carry each page or
  screen's route, heading, layout, blocks and origin; `/summary` gains app, page, screen
  and release counts. Existing fields are unchanged.
- Badges gain `success`, `warning`, `info`, `brand` and `neutral` tones and buttons gain
  `brand` and `soft` (dashboard components; not a public API).

## 3. Upgrade notes

- Nothing to change for apps. A package panel that styled itself with variables the
  dashboard never defined should switch to the listed tokens.
- The Grimoire tab's `ttlMs` now applies in production only when you set it; without it,
  the book is reused until it changes.

## 4. Measured

- Dashboard bundle: 141 KB gzipped (app.js 130.9 KB, app.css 10.1 KB), against 118 KB in
  5.56.0 and a 300 KB budget.
- Tests: devtools 957 server specs and 143 dashboard specs, grimoire 491 specs, all green;
  both packages typecheck.
