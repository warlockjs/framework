---
title: Sitemap
description: Runtime sitemap.xml generation — standalone in any Node app, in a Warlock API-only project via app-supplied entries, or from a Warlock web app's own page registry.
---

`@warlock.js/sitemap` builds `sitemap.xml` at **runtime**, against whatever
source of URLs your app has — a page registry, your own data, or both — with
exclusion rules (`noindex`, `sitemap: false`), per-entry `changefreq`/
`priority` defaults, and a loud diagnostic when a dynamic route can't be
enumerated. Generation only in this release; there is no remote sitemap
parser.

`@warlock.js/core` and `@warlock.js/web` are **optional peers**. Only the
connector reaches them, and only through a lazy `import()` at boot — nothing
else in the package imports from either. There are three ways to use it.

## Mode 1 — Standalone, any Node app

No Warlock at all. Build the page list yourself and call
`collectSitemapEntries` + `buildSitemapXml` directly — nothing on this path
resolves `@warlock.js/core` or `@warlock.js/web`.

→ [Standalone usage](./essentials/standalone/)

## Mode 2 — Warlock, API-only

An API-only Warlock app has no page registry to read. Pass
`sitemapConnector({ entries })` with your own supplier instead —
`@warlock.js/web` is not required on this path.

→ [Configuration](./essentials/configuration/#mode-2--warlock-api-only)

## Mode 3 — Warlock web

`warlock add sitemap` wires `sitemapConnector()` against the page registry
`@warlock.js/web` exposes, plus the page-level `sitemap` export for dynamic
routes.

→ [Configuration](./essentials/configuration/#mode-3--warlock-web)

## It needs your app's public origin (Modes 2 and 3)

The sitemap emits absolute URLs, so a `sitemapConnector()`-based setup needs
`app.publicUrl` (or the `PUBLIC_APP_URL` environment variable) set in
`src/config/app.ts`. With `sitemap.enabled: true` and neither set, **boot
refuses to start** rather than guessing the host from the incoming request —
see [Configuration](./essentials/configuration/). Mode 1 has no such
requirement: `buildSitemapXml(entries, origin)` takes the origin as an
argument.
