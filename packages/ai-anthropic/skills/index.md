# @warlock.js/ai-anthropic

This adapter supplies provider-backed models for `@warlock.js/ai`. Read `setup-anthropic.md` to construct `AnthropicSDK`, configure extended thinking, prompt caching, token counting and usage costs, and understand provider-specific behavior.

For agent composition, read the `run-ai-agent` topic of the `@warlock.js/ai` package. Keep provider configuration here and application orchestration in that package.
