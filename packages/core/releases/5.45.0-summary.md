# Warlock.js 5.45.0 — release summary

Released 2026-11-05.

All **33 packages** (`@warlock.js/*` and `create-warlock`) move to 5.45.0 together;
keep every family package on the same version. This release lets tools show images to
the model, meters compaction summaries with middleware, reports a context window for
every known model, and makes the AI workspace safer on Windows PowerShell 5.1. The
packages with code changes are `ai`, `ai-anthropic`, `ai-bedrock`, `ai-cli`,
`ai-deepseek`, `ai-google`, `ai-groq`, `ai-mistral`, `ai-ollama`, `ai-openai`,
`ai-tools`, `ai-workspace`, `ai-xai` and `process`.

---

## 1. Behaviour changes

- **Windows `interpreter: "auto"`** in `@warlock.js/ai-workspace` now tries `pwsh`
  (PowerShell 7+), then Git Bash, then Windows PowerShell 5.1, then `cmd.exe`. Only
  machines with Windows PowerShell 5.1 and Git Bash but no `pwsh` see a different shell.
  Pass `interpreter: "powershell"` to keep PowerShell.
- **Process setup gate**: `supervisor()` in `@warlock.js/process` waits 30 s for a child
  to reach its setup gate on Windows and macOS (5 s on Linux, as before). Set
  `setupTimeoutMs` to choose.
- **Spilled output text**: a `run_shell` or `shell_output` result that spilled its
  head and tail to disk now ends with a `[full output saved to <file>]` line.

---

## 2. Images in tool results (`ai`, adapters, `ai-tools`)

- A tool's `execute` can return `{ content: ToolResultPart[] }` with text and image parts.
  Anthropic, Bedrock Converse and OpenAI's Responses API send the images to the model;
  other providers get a text placeholder. `ModelCapabilities.toolResultImages` says
  which. Plain return values are serialised as before.
- MCP tools that return image content are forwarded as image parts.
- Clearing old tool results replaces image results with the cleared-result placeholder.

---

## 3. Compaction and context (`ai`, `ai-anthropic`)

- **`ai.compaction.summarize({ middleware })`** runs middleware such as `budget()` around
  every summary call, retries included. `ai.middleware.budget(...).wrapModel(model)`
  meters any direct `model.complete()` call the same way.
- **`lengthRetry`**: `false` turns off the retry after a summary cut by the output cap;
  `{ shrink }` sets how much input the retry keeps (default 0.7).
- **`clearToolResults.clearAtLeast`** skips clears that would free fewer tokens than the
  given number; Anthropic receives it as `clear_at_least`.

---

## 4. Context windows (all provider adapters)

- Every adapter's known chat models report `capabilities.contextWindow`, so
  window-relative compaction and clearing triggers work for Anthropic, OpenAI, Google,
  Bedrock, xAI, DeepSeek, Groq and Mistral models. Each model factory takes
  `contextWindow` to override.
- Ollama reads the window from `/api/show` after the first call; a configured
  `contextWindow` wins.
- `modelContextWindow(model)` returns a model's window, or `undefined`.

---

## 5. Workspace (`ai-workspace`)

- **Windows PowerShell 5.1** has its own `"powershell5"` dialect: a line with `&&` or
  `||` is refused with an explanation, and `run_shell`'s description says not to chain.
  `ResolvedShell` reports `edition` (`"desktop"` or `"core"`) and `version`.
- **Approvals**: an `onAsk` decision can `remember` several patterns, and
  `workspace.shell.remembered()` / `forget(pattern)` list and revoke them. A `reason`
  on a refusal reaches the model (up to 500 characters).
- **`spilledTo`**: every tool result that spilled output to disk lists the files in a
  flat `spilledTo` array.

---

## 6. Process (`process`)

- `supervisor({ pidWaitMs })` waits for a real process ID when a Windows terminal
  reports pid 0 right after spawn, and fails with `ProcessStartupError` (`reason:
  "no-pid"`) instead of supervising pid 0.
- Startup failures throw `ProcessStartupError` with `reason` `"no-pid"`, `"exited"` or
  `"setup-timeout"`.

---

## 7. Upgrade notes

1. **Update the family.** Run `npx warlock update`.
2. **Read what changed.** Run `npx warlock release-notes --from 5.44.0`.
3. **Workspace on Windows with PowerShell 5.1 and Git Bash?** `"auto"` now picks Git Bash;
   pass `interpreter: "powershell"` to keep PowerShell.
4. **Supervising processes on Windows or macOS?** The setup gate now waits 30 s; set
   `setupTimeoutMs: 5_000` for the previous limit.
