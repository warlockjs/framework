# Warlock.js 5.44.0 — release summary

Released 2026-11-05.

All **33 packages** (`@warlock.js/*` and `create-warlock`) move to 5.44.0 together;
keep every family package on the same version. This release makes long agent runs
cheaper and steadier (window-relative compaction, retries, cache routing and
diagnostics) and gives the AI workspace command rules, PowerShell and cmd support,
forgiving edits and output spill. Two defaults change (see below). The packages with
code changes are `ai`, `ai-anthropic`, `ai-openai`, `ai-google`, `ai-tools` and
`ai-workspace`.

---

## 1. Behaviour changes

- **Edit matching defaults to `"tiered"`** in `@warlock.js/ai-workspace`. Set
  `edit.matching: "exact"` for the previous exact-only behaviour.
- **`fetch_url` falls back to a built-in converter** in `text` / `markdown` mode when the
  readability peers are not installed, where it used to fail with `missing-peer`. Pass
  `extractor: "readability"` to keep the strict error. It also retries once on a
  `cf-mitigated: challenge` response; set `retryOnChallenge: false` to disable that.

---

## 2. Compaction and context (`ai`)

- **Window-relative triggers.** `compaction.afterTokens` and
  `contextEditing.clearToolResults.afterTokens` accept `{ share, reserve?, max? }` as well
  as a number, resolved against the new `capabilities.contextWindow` of the model.
  `anthropic.model`, `openai.model` and `google.model` take `contextWindow` and know the
  windows of common models; an unknown model leaves the trigger idle.
- **Summariser input degradation.** `ai.compaction.summarize({ input })` shrinks what is
  sent to the summary model, never the live history: `maxInputTokens`,
  `clipToolOutputChars`, `dropToolOutputsOlderThan` and `shrinkOnContextError` retries.
- **`requireHeadings`** checks the summary for the headings you need and sends exactly one
  corrective follow-up before the compaction is skipped as a `callback-error`.
  Compaction records carry `summarizerInputTokens` and `attempts`.

---

## 3. Resilience and caching (`ai`, `ai-openai`)

- **`ai.retryModel(model, policy?)`** retries transient failures on the same model with
  backoff and jitter before they reach the caller.
- **`cacheControl.key`** is a routing key for prompt caching; OpenAI-compatible providers
  that take one send it as `prompt_cache_key`.
- **Prompt fingerprint diagnostics** (opt-in): `agent({ diagnostics: { cacheFingerprint:
  true } })` hashes the system prompt, tool definitions and message prefix of every trip,
  so you can see which part changed when a cache stops hitting.

---

## 4. Workspace (`ai-workspace`)

- **Command rules.** `shell.rules` is an ordered list of `allow` / `ask` / `deny` rules,
  and `shell.onAsk` decides on commands that need approval. `workspace.shell.classify(line)`
  and `classifyShellCommand` show what a line would run.
- **Interpreters.** `shell.interpreter` accepts `"bash"`, `"powershell"`, `"cmd"` and
  `"auto"`, each with its own parser feeding the same deny, allow and path-jail checks.
- **Tiered edit matching.** `edit_file` and `multi_edit` match exactly, then with line
  endings normalised, then with look-alike punctuation folded, then ignoring trailing
  whitespace. A loose match must be unique, and replacements keep the file's line endings.
  A miss carries a `hint` with the closest text.
- **`policy.hooks.afterEdit`** runs after file writes and returns diagnostics (a type check,
  for example) in the result; it never fails the edit.
- **Output spill.** With `policy.output.spillDir`, oversized shell, grep, glob and read
  output is saved to a file and the result keeps its head, tail and the file path.

---

## 5. Web tools (`ai-tools`)

- **`fetch_url` `extractor`**: `"auto"` (default), `"readability"` or `"simple"`; the result
  names the converter used. A multi-byte character is no longer split at `maxBytes`.

---

## 6. Upgrade notes

1. **Update the family.** Run `npx warlock update`.
2. **Read what changed.** Run `npx warlock release-notes --from 5.43.0`.
3. **Relying on exact edit matching?** Set `edit.matching: "exact"`.
4. **Relying on the `missing-peer` error from `fetch_url`?** Pass `extractor: "readability"`.
   Set `retryOnChallenge: false` if you do not want the one retry on a challenge response.
5. **Window-relative triggers on a custom model?** Give the model a `contextWindow`.
