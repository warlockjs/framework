# Warlock.js 5.54.0 — release summary

Released 2026-11-16.

All **33 packages** (`@warlock.js/*` and `create-warlock`) move to 5.54.0 together;
keep every family package on the same version. This minor adds batched model loading,
mass-assignment protection and MongoDB relation filters in `cascade`, key rotation and
password rehashing, guardrails for tool results in `ai`, a faster and lighter page
render in `web`, and a cancelled error category for the AI providers. It also prepares
the 6.0 defaults: the ones that change warn now, and the generated app already sets
the safe values. The packages with changes are `access`, `ai`, `ai-anthropic`,
`ai-bedrock`, `ai-cli`, `ai-google`, `ai-ollama`, `ai-openai`, `ai-panoptic`,
`ai-tools`, `ai-workspace`, `auth`, `cache`, `cascade`, `context`, `core`,
`create-warlock`, `logger`, `queue`, `scheduler`, `seal` and `web`. Several behaviours
change; every one is listed under "Upgrade notes" with the setting that restores the
old behaviour, where there is one.

## Check first

- **`find()` and `load()` are batched.** `Model.find(id)` calls and `model.load(...)`
  calls made in the same tick now run one query (one `whereIn`, one relation load), so
  query listeners and query counts see one query where they saw several. A global scope
  that reads its own `AsyncLocalStorage` (not a `@warlock.js/context` context) cannot be
  told apart between callers: set `static batchLoads = false` on that model.
- **Reset and OTP mail is sent in the background.** `requestPasswordReset()` and
  `requestOtp()` now do the lookup, the token or code writes and the delivery after the
  response. Code that read the new token row right after the call must set
  `auth.passwordReset.awaitDelivery: true` (or `auth.otp.awaitDelivery`) or read it from
  the delivery. Failures are emitted as `password.resetDeliveryFailed` /
  `otp.deliveryFailed`.
- **Old local-disk temporary URL tokens are refused.** Tokens issued by earlier
  versions fail with `invalid_token`; issue the links again.
- **Locale order.** When a request sends both a `locale` header and a `locale` cookie
  with different values, the header now wins. The order is `?locale=`, the
  `warlock.locale-preference` cookie (only for values in `app.localeCodes`), the
  `locale` header, the `locale` cookie, then `app.localeCode`.
- **The API 404 body is translated.** A request that matches no route gets
  `{ error, code: "route_not_found", path, method, requestId }`, and `error` follows the
  request locale. Clients that compared `error` with "Route not found" should switch on
  `code`.
- **`grep` is capped at 1000 states** (was 4000). Patterns with very large bounded
  repeats may now be refused as `unsafe-pattern`.
- **Abort is now "cancelled" in `ai-google` and `ai-ollama`.** A call cancelled through
  its own `signal` raises `ProviderAbortError` instead of `ProviderTimeoutError`. Catch
  `ProviderAbortError`, or check `category === "cancelled"`.
- **`http.input.maxDepth` is on (32).** A JSON body nested deeper is refused with 400
  `EC111`, and deeper query, urlencoded and multipart keys are dropped. Raise
  `http.input.maxDepth` if an endpoint takes deeper input.
- **Cloud markup downloads.** Cloud disks store svg, html, xml and script files with
  `Content-Disposition: attachment`. Pass `contentDisposition: "inline"` in the put
  options for a markup file the bucket must serve inline.
- **`@mongez/react-form` 4.1 (`web`, new apps).** Control ids inside a `<Form>` are now
  `<formId>-<name>` instead of `input-<name>`, and a `<Form>` renders `method="post"`
  unless you pass a `method`. Update selectors and tests, or pass an explicit `id`.
- **`.env` grammar (`@mongez/dotenv` 2).** Single-quoted values are literal, double
  quotes expand `\n`, `\t`, `\\` and `\$`, a `#` after whitespace on an unquoted value
  starts a comment, and an unterminated quote throws. Check `.env` files for values with
  `#`, backslashes or single-quoted `${...}`.
- **`trim`, `ltrim` and `rtrim` needles (`seal`).** A multi-character needle is removed
  as a whole, repeatedly (`"ababXab"` trimmed with `"ab"` is `"X"`, was `"abX"`), and an
  empty needle leaves the string unchanged.

## 1. What changed most

- **Mass assignment and tenants (`cascade`).** `static guarded` lists columns that
  `merge()`, `set()`, `create()`, `createMany()`, `save({ merge })`, `findOrCreate()` and
  `upsert()` never write, so `user.merge(request.all())` cannot set `role`. Global scopes
  take a `stamp` option that writes tenant values into inserts when the column is unset.
  Request input methods mark their result as raw, and merging it into a model warns once
  in development.
- **Batched loading (`cascade`, `context`).** Same-tick `find()` and `load()` calls are
  grouped per model class and per `@warlock.js/context` scope, so a tenant scope always
  sees its own caller's tenant. A lone call, a repeated id and any call in a transaction
  run as before.
- **MongoDB parity (`cascade`).** `has()`, `whereHas()`, `orWhereHas()`, `doesntHave()`
  and `whereDoesntHave()` work for hasMany, hasOne, belongsTo and belongsToMany; `withCount()`
  adds the related count; `joinWith()` loads relations instead of doing nothing. A write
  on a query holding a relation filter still throws; resolve ids with `pluck()` and write
  with `whereIn()`.
- **Key and password rotation (`core`, `auth`).** `encryption.previousKeys` and
  `auth.accessToken.previousSecrets` / `auth.refreshToken.previousSecrets` rotate keys
  without losing ciphertexts or signing users out. `needsRehash()` and
  `auth.rehashPasswords` (default `true`) upgrade stored hashes at login. The new
  `encryption.password.driver: "scrypt"` has no 72-byte limit. `warlock doctor` warns
  (`WL1019`) while retired keys remain.
- **Tool results and failover (`ai`).** `ai.guardrail` has a `toolResult` phase that
  checks what a tool returned before the model reads it, and `wrapToolResults: true`
  wraps results as untrusted data. `fallbackModel` takes `alsoRetryOn`, and a caller's
  own cancellation never advances the chain.
- **Provider errors (`ai-openai`, `ai-google`, `ai-anthropic`, `ai-bedrock`,
  `ai-ollama`).** `ProviderAbortError` (category `cancelled`, never retried) is raised
  for a caller's own abort. A spent quota or billing allowance maps to
  `QuotaExceededError` instead of a retryable rate limit; DeepSeek, Groq, xAI and
  Mistral share the OpenAI mapping.
- **Pages (`web`).** A client navigation renders once, in the browser; the inline
  hydration payload is smaller; error and forbidden pages are lazy chunks. New
  `web.shellTimeout` and opt-in `web.earlyHints`. Pages can declare `config.uploads`,
  and sites can have their own `robots`.
- **Uploads and requests (`core`).** `http.multipart.memoryLimit` streams large file
  parts to a temporary file; route `uploads` takes `maxFileSize` and `maxFiles`.
- **Access (`access`).** `DefaultAccessResolver` reads roles and permissions from the
  loaded user on every check, so a role change shows on the next request.

## 2. Performance

- **Queries (`cascade`).** Several `find()` calls run one `whereIn`; `load()` calls with
  the same relations run one relation load; hydrating a row resolves the data source once
  per result set; PostgreSQL attaches column types once per result; a model with no sync
  listeners queues no fan-out job; a MongoDB upsert that updates reserves no id.
  `query.stream()` reads one batch per round trip, `query.atomic()` is one statement, and
  PostgreSQL `query.prepare(name)` plans a hot query once per connection.
- **Sign out everywhere (`auth`).** `revokeAllTokens()` works in bulk: one read and one
  insert for the token families, one update to revoke them, and one update for refresh
  tokens, instead of a transaction per family.
- **Pages (`web`).** A client navigation no longer renders on the server; the inline
  payload drops repeated slots; page-cache HITs carry a weak `ETag` and answer `304`;
  with `http.compression` on, entries are compressed once when stored; production
  translation delivery reuses a route's pruned dictionary per locale.
- **Cache (`cache`).** `has()` uses the driver's `exists()` and reads no value.
  `similar()` takes a `filter` that runs before `threshold` and `topK`, so scoped recalls
  need one query.
- **AI recalls and sessions (`ai`).** Scoped recalls are one query on stores that
  filter before ranking; `rag.clear()` lists the namespace and deletes exactly its own
  chunks; `ai.session` writes the full record once per turn on stores with `markPending`.
- **Core.** Repositories can invalidate their cache in constant time with
  `repository.cacheInvalidation: "generation"`; the `database` cache driver can upsert in
  one statement (`upsert: true`) and reads a plain row; the rate limiter releases its
  buckets with its middleware.
- **Seal.** Nested object output is cleaned of `undefined` once, so the cost no longer
  grows with nesting depth, and a rule that answers without a promise skips a microtask
  hop.
- **Queue and dashboard.** The SQLite store indexes the finish time used by pruning and
  the memory store polls only jobs that can still run. The Panoptic `GET api/traces`
  sends an `ETag`, so an idle dashboard transfers almost nothing.
- **`ai-workspace`.** `glob` and `grep`'s `glob` option yield to the event loop between
  entries and honour the abort signal.

## 4. Upgrade notes

Most likely to be noticed first. Each line ends with the way back, where there is one.

1. **Update the family.** Run `npx warlock update`, then
   `npx warlock release-notes --from 5.53.0`. `warlock update` now refuses to install
   with an npm older than 11.6.2 and changes nothing; use a newer npm, or run
   `warlock update --no-install` and install yourself. If the install fails it puts
   `package.json` (and `package-lock.json`) back as they were.
2. `find()` and `load()` calls in one tick run as one query → `static batchLoads = false`
   on the model.
3. `requestPasswordReset()` / `requestOtp()` finish their work after the response →
   `auth.passwordReset.awaitDelivery: true` / `auth.otp.awaitDelivery: true`, or listen to
   `password.resetDeliveryFailed` / `otp.deliveryFailed`.
4. `attemptLogin()` (so `login()`) replaces a stored password hash made with another
   algorithm or cost → `auth.rehashPasswords: false`. A failure to save is logged and
   never fails the login.
5. A successful login no longer clears the shared IP bucket of
   `loginThrottleMiddleware()` when an account bucket is tracked next to it; with
   `by: ["ip"]` alone it still does.
6. `DefaultAccessResolver` no longer caches roles and permissions → memoize an expensive
   custom `readRoles`; other resolvers keep their cached behaviour; set
   `readonly cacheable = false` on a resolver to skip the cache.
7. Local-disk temporary URL tokens carry the issuing disk's name (token format 3); older
   tokens answer `invalid_token` → issue new links. A hand-made `LocalDriver` takes the
   disk name as its second constructor argument.
8. Request locale: the `locale` header wins over the `locale` cookie → send only one of
   them, or send equal values.
9. Unmatched routes answer `route_not_found` with `requestId` and a translated `error` →
   switch on `code`, or define `web.errors.routeNotFound`.
10. `Restful.list` rethrows a failure other than a refused filter, so the request funnel
    answers and records it as any other 5xx.
11. `v.file().mimeType()` failures read "The File must be a image/png, image/jpeg file"
    and the schema refuses a wrong type with 422.
12. `http.multipart.routes` still defaults to `"all"`; the production warning now says it
    becomes `"declared"` in 6.0 → set `"declared"` now and mark file routes with
    `uploads: true` (pages: `config.uploads: true`).
13. JSON bodies nested deeper than 32 levels answer 400 `EC111`; deeper query,
    urlencoded and multipart keys are dropped → `http.input.maxDepth`.
14. Cloud disks store markup files with `Content-Disposition: attachment` → pass
    `contentDisposition: "inline"` in the put options. An svg in an `<img>` tag still
    renders.
15. `.env` files follow the `@mongez/dotenv` 2 grammar (see "Check first") → quote and
    escape values as described there. Core still passes `precedence: "process-wins"`.
16. `ai-google` and `ai-ollama` raise `ProviderAbortError` for the call's own abort →
    catch it, or check `category === "cancelled"`. `TimeoutError` (for example from
    `AbortSignal.timeout()`) and `ETIMEDOUT` stay timeouts; in `ai-google` an abort the
    caller did not ask for, such as the SDK's `httpOptions.timeout`, stays a
    `ProviderTimeoutError`, as do `504` and `DEADLINE_EXCEEDED`.
17. A 429 with an `insufficient_quota` type, or a billing code, maps to
    `QuotaExceededError`, which is not retried and does not advance the default fallback
    chain → add `PROVIDER_QUOTA_EXCEEDED` through `alsoRetryOn` to switch providers when
    credit runs out. `ai-google` maps a spent quota the same way; per-minute and per-day
    limits stay rate limits.
18. `agent.execute()` and `agent.stream()` refuse a non-string `input` with an
    `InvalidRequestError` → pass the prompt text.
19. Workspace `grep` patterns may expand to at most 1000 states → rewrite the pattern.
20. The `has()` cache events `hit` and `miss` carry the key only, without `value`.
21. `trim`, `ltrim` and `rtrim` with a multi-character needle remove it whole and
    repeatedly; an empty needle changes nothing → single-character needles behave as
    before.
22. `web`: a client navigation no longer renders on the server, so a component that
    throws while rendering is found by the browser and reported through `web.errors` and
    `onClientError` (with the route name).
23. `web`: code that read stylesheet, preload, `hreflang`, hydration entry or site-key
    slots out of `#__WARLOCK_DATA__` should read the document's `<link>` and `<script>`
    elements (they carry `data-wl`).
24. `web`: a page that suspends outside every `<Suspense>` boundary for more than 30 s
    (90 s under `warlock dev`) answers the error page with 504 → `web.shellTimeout`
    (`0` turns it off).
25. `web`: a generated client registry exposes `loadErrorPage` and `loadForbiddenPage`;
    hand-written registries that pass the modules keep working.
26. `@mongez/react-form` 4.1 control ids are `<formId>-<name>`, and a `<Form>` posts
    natively → pass an explicit `id` or `method`; update `#input-<name>` selectors.
27. `JSONFileLog` without `format` warns once per process (not under test) → `format:
    "json"` to keep the layout, `"jsonl"` to switch now.
28. `ai.serve` logs that it will refuse to start without `authToken`, `authorize` or
    `public: true` in 6.0; nothing else changes in 5.x.
29. Cascade: a MongoDB upsert generates its `id` in a second write after the insert, so
    a crash between the writes leaves the document without `id` → supply `id` in
    `$setOnInsert`, or use a transaction. A failing sync-event listener is retried on its
    own (3 attempts) and reported once.
30. Cascade: `cursorPaginate()` now reads the cursor column with `model.get(column)`, and
    `findAndUpdate(filter, ops, { upsert: true })` updates every matching row.
31. `glob` moves to `^14.0.3` in `core` (used by the `e2e` command only).
32. New apps only: existing apps keep their files. The generated app sets
    `http.multipart.routes: "declared"`, `loginThrottleMiddleware({ emailLock: "pair" })`,
    `guarded = ["role"]` on `User`, `statement_timeout: 30_000` on PostgreSQL and a
    `trustProxy` note that recommends IP addresses or CIDR blocks. Copy what you want
    from a fresh app.

## 5. Planned for 6.0

These defaults warn or log in 5.54 and change in 6.0. Set them explicitly now to choose.

- **Coding-CLI `inheritEnv` (`ai-cli`).** It stays `true` in 5.x and the production
  warning when it is unset stays. In 6.0 it becomes `"curated"`: `apiKeyEnv` plus each
  adapter's `passEnv` list, which every built-in adapter declares. Set `"curated"` to
  adopt it, or `true` to keep inheriting the whole environment.
- **Six safe defaults.** Each one warns once now, or is already set in the generated app:
  - `http.multipart.routes`: `"all"` becomes `"declared"` (`core`).
  - `loginThrottleMiddleware({ emailLock })`: `"global"` becomes `"pair"` when email and
    IP are both tracked (`auth`).
  - `auth.passkeys.userVerification`: `"preferred"` becomes `"required"` (`auth`).
  - A JWT secret shorter than 32 bytes becomes a boot error (`auth`).
  - `JSONFileLog` `format`: `"json"` becomes `"jsonl"` (`logger`).
  - `ai.serve` refuses to start without `authToken`, `authorize` or `public: true`
    (`ai`).
- **Synchronous validation types (`seal`).** 5.54 skips the `await` when a rule or
  mutator returns a non-promise, and the public types are unchanged. In 6.0 the rule and
  mutator types are planned to accept non-promise results, with synchronous built-in
  rules.

## Verification

- The release tree passed the typecheck of every package, every package's unit tests
  (22,053 tests, none failing, 29 skipped), format, lint, the strictness ratchet, the
  public-text, skill, feature-parity and advisory gates, the release-tool tests and the
  docs build in one final pass.
- The whole change was read by an independent reviewer after it was written; the
  regressions it found were fixed before that final pass. The release gate also runs
  every package's tests and the blog app on the tarballs.
- Run against live services: the auth hardening suites on MongoDB and PostgreSQL, the
  login throttle, rate limit and cache specs on Redis, and the cascade atomic-update,
  lean-read, pipeline, raw-stage, pending-migration and relation-existence suites.
- Not run: the container-based integration suites, a live RabbitMQ broker, the AI
  checkpoint stores on PostgreSQL and Redis, and a live DNS-rebinding test.
