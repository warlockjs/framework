# Warlock.js 5.62.0 — release summary

Released 2026-11-20.

All **34 packages** (`@warlock.js/*` and `create-warlock`) move to 5.62.0 together;
keep every family package on the same version. This minor fixes three AI issues found in a
production app: Anthropic agents that set a system-prompt cache breakpoint lost conversation
caching, image, speech and transcription runs showed no model, and the production monitor's
Runs and Agents tabs could be turned on but stayed empty. The packages with changes are
`ai-anthropic`, `ai-panoptic` and `devtools`.

## Check first

- If an Anthropic agent sets `modelOptions: { cacheControl: { breakpoints: 1 } }` with
  `promptCaching: true`, its later trips now read the conversation history from cache again.
  Nothing to change; expect lower input cost.
- If `devtools.production.panels` sets `ai` or `agents` to `true`, those tabs are no longer
  listed in production and one warning is logged at boot. Use Reports, Models and Errors there.

---

## 1. What changed most

- **Anthropic: a system breakpoint no longer turns off conversation caching.** With
  `promptCaching: true`, a per-call `cacheControl: { breakpoints: n }` used to replace the
  request-level `cache_control` marker, so a multi-trip agent stopped reading its history from
  cache (measured on a 27K-token, two-trip call: 0 cached tokens on the second trip instead of
  about 27K). The automatic marker, the tools marker and the system marker are now sent together,
  3 of the 4 breakpoints a request may carry.
- **Image, speech and transcription runs show their model.** Their Panoptic spans carry the
  model and size (`image.model.name`, `image.model.provider`, `image.count`, and the matching
  `speech.*` and `transcription.*` keys). Devtools shows the model in the Runs page, the run
  summary and the AI totals instead of `(unknown)`.
- **Production keeps Runs and Agents in development.** Production shows AI totals in Reports,
  Models and Errors. Turning on the Runs or Agents tab in production used to list a tab that
  never filled; the flags are now ignored with one warning at boot.

## 2. New options and APIs

- **Panoptic span attributes.** `image.model.name`, `image.model.provider`, `image.count`,
  `speech.model.name`, `speech.model.provider`, `speech.characters`,
  `transcription.model.name`, `transcription.model.provider`, `transcription.durationSeconds`.

## 3. Upgrade notes

- AI totals saved before the upgrade keep image, speech and transcription runs under
  `(unknown)`, so a range that spans the upgrade lists both rows.
- Exporters forward the new span attributes as they are (OTel attributes, Langfuse metadata).

## 4. Verified

- Each issue was reproduced on 5.61.0 with a spec before the fix; the specs now pass as regression tests.
- One typecheck of the family, the strictness gate and every package's full test suite ran green on the final tree,
  along with format, lint, the public-text, skill and release-note checks, the devtools UI gate and the docs build.
