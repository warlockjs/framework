# Warlock.js 5.47.0 — release summary

Released 2026-11-06.

All **33 packages** (`@warlock.js/*` and `create-warlock`) move to 5.47.0 together;
keep every family package on the same version. This release fixes issues found in
two apps running 5.45 and 5.46: image tool results no longer cost text tokens on later
turns, workspace search skips dependency folders, PostgreSQL date helpers run in UTC,
page routes accept SEO-style segments, and the test server always loads the app's
modules. The packages with code changes are `ai`, `ai-anthropic`, `ai-deepseek`,
`ai-google`, `ai-groq`, `ai-mistral`, `ai-openai`, `ai-tools`, `ai-workspace`,
`ai-xai`, `cascade`, `core`, `seal` and `web`.

---

## 1. Behaviour changes

- **PostgreSQL session time zone**: every connection starts in `UTC`, so
  `groupByDate`, `whereDate*` and raw SQL such as `now()::date` match how dates are
  stored. Set `timezone` in the connection options to choose another zone, or
  `timezone: false` to keep the server's.
- **Workspace search**: `glob` and `grep` no longer search `node_modules`, `.git` or
  gitignored paths by default (`search.skipDirs` and `search.gitignore` restore them).
- **Bash on Windows**: a command with an unquoted Windows-style path
  (`cd ab\x\y`) is refused with the forward-slash form in the message.
- **Model lists**: retired ids left `GROQ_KNOWN_MODELS` and `DEEPSEEK_CHAT_MODELS`;
  they are marked `retired` in the new lifecycle tables and still accepted by
  `model({ name })`.

---

## 2. AI sessions and tools (`ai`, `ai-tools`)

- `ai.session` stores image tool results as parts, so later turns send the image as an
  image instead of paying for its base64 as text. Records saved by 5.45 and 5.46 are
  repaired when they load.
- Token estimates count an image, PDF or audio part as a fixed 1,000 tokens.
- MCP over http: `ai.mcp({ type: "http", url, fetch })` takes a custom `fetch` for calls
  longer than 300 seconds, and a stalled response is reported as `type: "timeout"` with
  its cause.

---

## 3. Workspace (`ai-workspace`)

- `glob` and `grep` start at the pattern's folder, skip `node_modules`, `.git` and
  gitignored paths, honour the run's signal and stop at `search.maxFiles`.
- `hooks.onShellOutput` streams `run_shell` output while a command runs, for
  foreground commands and background jobs, line-buffered and throttled.

---

## 4. Model tables (`ai` and the provider adapters)

- `ModelPricing` supports prompt-length `tiers` and dated `schedule` changes, which
  `computeCost` applies.
- Each adapter has a model lifecycle table (`current`, `retiring`, `retired`) and dated
  price tables. New models and context windows for OpenAI, Anthropic, Google, xAI,
  Groq, DeepSeek and Mistral, each checked against the vendor's pages.

---

## 5. Database (`cascade`)

- `saved`, `created` and `updated` listeners receive the save's changes (`changes`,
  with each column's `oldValue` and `newValue`), and `model.getLastSaveChanges()` returns
  them after the save. Before, the changes were already cleared when these events ran.
- PostgreSQL pool config takes `timezone` and `options` and forwards every other option
  `pg` accepts; an app's own `TimeZone` in `options` or the connection string wins.
- `model.isFilled(field)` is true when a field is neither `null` nor `undefined`. On
  PostgreSQL an unset column reads back as `null`, so check it with `isFilled` or `== null`.

---

## 6. Web (`web`)

- Page routes accept several params and static text in one segment
  (`/:type-for-:purpose`, `/near/:lat-:lng`) and a named wildcard (`/files/*rest`).
  The server and browser split a segment the same way, and two routes that could
  match the same URL with equal priority are refused at startup. Existing routes and
  API-route types are unchanged.

---

## 7. Uploads and tests (`core`, `seal`)

- `v.array(v.file())` accepts a single file sent without `[]`, and
  `request.files(name)` returns it as a one-element array.
- `createTestHttpServer({ loadAppModules: true })` loads the app's routes and
  `main.ts` files again (they were discovered but never loaded), and throws when a
  project with modules loads none.

---

## 8. Upgrade notes

1. **Update the family.** Run `npx warlock update`.
2. **Read what changed.** Run `npx warlock release-notes --from 5.46.0`.
3. **PostgreSQL on a server not set to UTC, with raw SQL that relied on the server's
   zone?** Set `timezone` in the connection options.
4. **Searching inside `node_modules` with the workspace tools?** Set
   `search.skipDirs: [".git"]`.
