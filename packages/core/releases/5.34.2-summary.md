# Warlock.js 5.34.2 — release summary

Released 2026-10-19.

All **33 packages** (`@warlock.js/*` and `create-warlock`) move to 5.34.2 together;
keep every family package on the same version. This patch changes only the
skills that ship with the packages. There are **no runtime or API changes**.

---

## One skill per package, with a complete index

Apps receive each package's skills through `agent-kit` as one skill: its
`SKILL.md` describes the package and links every topic file beside it. This
release makes every package's index complete and accurate:

- **Framework issue reporting reaches apps.** The guidance for preparing a
  public framework bug report or feature request was a loose file that
  `agent-kit` never exported. It is now the `report-framework-issue` topic of
  `@warlock.js/core`, delivered as `report-framework-issue.md` inside the core
  skill.
- **Every topic is listed** in its package's index, and stale references are
  fixed (for example, the AI tools index now points to the `@warlock.js/ai`
  tool-definition topic instead of a missing sibling file).
- **No duplicate overviews.** Nine packages had an `overview` topic repeating
  their index; its content is merged into the index and the topic removed
  (access, auth, cache, context, fs, logger, queue, scheduler, seal).
- **No second catalog.** The hand-maintained `skills/README.md` lists, which had
  drifted from the indexes, are removed; package READMEs link to
  `skills/index.md`.

After upgrading, re-run `npx agent-kit sync` (or reinstall) so the app's agent
skills pick up the new layout.

---

## Release tooling

The skill path check now also fails when a package index names a topic that does
not exist, leaves out one of its topics, or a package ships a loose skill file
that `agent-kit` would not export. It runs in CI and in the release gate.
